# 蜗牛 4K

在插件设置中填写蜗牛 4K 登录账号和密码，即可按片名搜索 115 分享和磁力链接。使用你有权访问的账号和资源。

「每次获取数量」默认为 5 条，可设置为 1 至 20 条。该数量为两种资源合计，Muvyo 查询也可以进一步缩小数量。「资源类型」可选择两种资源，或仅搜索其中一种。

选中资源后，插件从对应影片详情重新读取链接及 115 提取码。插件联网访问 `www.wn4k.com`，默认直连；「连接方式」选择「使用系统代理」后，经 Muvyo 已配置的系统代理访问。后续保存或下载由 Muvyo 处理。

同一账号的搜索请求（含翻页）至少间隔 3 秒。遇到站点明确的搜索间隔提示时，插件按站点要求等待，并最多重试该次请求一次。等待计入本次执行时限，预算不足时返回已取得的结果。

网络请求失败时，插件显示失败阶段（登录、搜索或详情）及固定的网络错误分类，并写入插件日志；不记录账号、Cookie 或原始网络异常。

同时保留 `resolve` 和 `resolveLink` 换链入口，使用相同的资源校验和登录会话。
