# 聚影

在插件设置中填写聚影登录账号和密码，即可按片名搜索 115 分享和磁力链接。使用你有权访问的账号和资源。

「每次获取数量」默认为 5 条，可设置为 1 至 20 条。该数量为两种资源合计，Muvyo 查询也可以进一步缩小数量。「资源类型」可选择两种资源，或仅搜索其中一种。

结果包含可访问的免费或已解锁资源。选中资源后，插件从聚影取得最新的链接及 115 提取码。插件直连 `www.jying.top`，后续保存或下载由 Muvyo 处理。

收到 HTTP 429 后，插件按站点返回的 `Retry-After` 暂停该账号的请求。缺少有效时间时使用插件设定的 60 秒冷却。冷却结束后再次搜索或解析时会继续使用有效的登录状态。

兼容通过 `resolve` 或 `resolveLink` 获取资源链接的宿主版本；两种入口使用相同的账号会话、资源校验和返回格式。
